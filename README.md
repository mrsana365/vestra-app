# 🛒 Full Stack eCommerce Website

Vestra is a full-stack eCommerce web application where users can explore products, filter and sort them, select variants (like size), add them to the cart, and place orders using multiple payment methods. The platform also includes an admin dashboard for product and order management. This project leverages modern web technologies, payment gateways (Stripe & Razorpay), and a robust backend API built with Node.js, Express, and MongoDB.

---

## 🌐 Features

### 🧑‍💻 **User Features**
- Browse a wide range of products.
- Filter and sort products based on preferences (e.g., category, price, size).
- View detailed product descriptions and available variants (like size).
- Add products to the cart with selected variants.
- Place orders by providing delivery address.
- Choose from:
  - **Cash on Delivery (COD)**
  - **Online Payments** via:
    - 🟠 Razorpay

---

### 🛠️ **Admin Features**
- Secure admin dashboard.
- Add/upload new products to the store.
- Delete or update existing products.
- View all available products in the store.
- Monitor customer orders and order status.
